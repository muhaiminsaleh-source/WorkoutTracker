# Workout Tracker — C# & .NET Project Evolution Portfolio

A progressive C# / .NET portfolio project demonstrating the evolution of a single domain (**Workout Tracker**) from a basic console application to a layered architecture, relational database integration, and a RESTful ASP.NET Core Web API.

## Project Structure & Milestones

| Milestone | Project Folder | Key Concepts & Technologies |
| :--- | :--- | :--- |
| **Milestone 01** | `Milestone01_BasicConsole` | Console I/O, menu-driven CLI, JSON file persistence |
| **Milestone 02** | `Milestone02_OOP` | Object-Oriented Programming (Classes, Encapsulation, Methods) |
| **Milestone 03** | `Milestone03_Layered` | Layered Architecture (`Models`, `Repositories`, `Services`), Dependency Injection via interfaces (`IWorkoutRepository`) |
| **Milestone 04** | `Milestone04_Database` | Relational Database with **Entity Framework Core** & **SQLite** (`workouts.db`), LINQ queries, full CRUD |
| **Milestone 05** | `Milestone05_WebApi` | **ASP.NET Core Web API**, RESTful endpoints (`GET`, `POST`, `PUT`, `DELETE`), EF Core SQLite (`workouts_api.db`) |

## Tech Stack

- **Language:** C#
- **Framework:** .NET 10.0 / ASP.NET Core
- **ORM & Database:** Entity Framework Core, SQLite
- **IDE:** Visual Studio (Windows)
